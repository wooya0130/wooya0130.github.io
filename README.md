# wooya0130.github.io

A Jekyll blog built from scratch — no theme, managed entirely in the browser.

Guide → [github-blog-guide](https://github.com/wooya-study/github-blog-guide)

## Structure

```
_config.yml             data
_layouts/default.html   frame
index.html              content
```

Data is pulled in, the frame wraps around, content stays in its own file. Change one thing in one place.

## Rules

- No `theme`.
- Paths use `| relative_url`.
- Add features only when needed.

# wooya0130.github.io

남의 테마 없이 직접 만든 Jekyll 블로그. 브라우저만으로 관리한다.

가이드 → [github-blog-guide](https://github.com/wooya-study/github-blog-guide)

## 구조

```
_config.yml             데이터
_layouts/default.html   뼈대
index.html              내용
```

데이터는 꺼내 쓰고, 뼈대가 감싸고, 내용은 자기 파일에만 둔다. 하나를 바꿀 때 한 곳만 고친다.

## 규칙

- `theme`을 쓰지 않는다.
- 경로에 `| relative_url`을 붙인다.
- 기능은 필요해질 때 추가한다.
